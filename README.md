SOS Bharat – Emergency Alert App

A front-end mobile application built using React Native (Expo) that helps users quickly send SOS alerts with live GPS location to saved emergency contacts.

🚨 Features

One-tap SOS alert with GPS location

Send alerts via SMS

Add & manage emergency contacts

Direct 112 emergency call

Multiple emergency categories (Police, Fire, Medical, Women, etc.)

Smooth UI with animations, OTP login & state selector

🛠️ Technology Used

-React Native (Expo)

=JavaScript (ES6)

=Expo-Location API

-Expo-SMS

-React Navigation

-AsyncStorage
